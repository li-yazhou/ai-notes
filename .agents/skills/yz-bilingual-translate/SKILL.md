# 中英对照翻译（arXiv 论文 / 在线英文文章）

把英文文章/论文按段落翻译为中英对照，图片本地化，保存为独立文件夹。默认只翻正文、不翻附录。

## 何时使用

- 用户给出一篇 arXiv 链接（`arxiv.org/abs/…` 或 `arxiv.org/html/…`）或在线英文文章链接，要求翻译成中英对照/双语版。
- 用户说"把这篇翻成中英对照""做个双语版""翻译这篇论文/文章"等。
- 注意区分：**只保存原文、不翻译**的需求用 `yz-save-online-article`；本 skill 专用于**中英对照翻译**。

## 核心流程

**优先用脚本提取正文与图片**，再由模型逐段翻译：

```bash
python3 <skill目录>/scripts/extract_article.py <URL> <目标目录>
```

- 目标目录：**每次调用时由用户指定**（如 `02-agent/01-agent`）。用户没说时先询问，不要自作主张挑目录。
- 脚本自动区分 arXiv（LaTeXML HTML 解析）与普通网页（readability 提取），下载图片到 `<目标目录>/<文件夹>/images/`，并写出 `extracted.md`（英文正文，含章节/段落/图表，图片已本地化引用）。

### 具体步骤

1. **确认输入**：取出 URL 与目标目录；缺哪个问哪个。
2. **运行脚本**，逐条看 stdout：
   - 标题是否正确、章节结构是否完整；
   - 图片数量与 `images/` 实际文件是否对应；
   - 是否有"下载失败"提示。
3. **读 `extracted.md`**，判断正文范围：
   - arXiv：找到"Introduction ~ Conclusion + Acknowledgments"，**跳过 Appendix A+**（除非用户要求翻译附录）；
   - 网页：提取主体内容，跳过页脚/无关尾部。
4. **逐段翻译**为中英对照（格式见下），写入最终 md。
5. **校验**：图片引用与 `images/` 文件一一对应；脚注/表格/数学公式完整；附录确未收录并在文末注明。
6. **不自动提交 git**：翻译完成后不 `git commit`，由用户决定。

## 命名与结构

- YYMM 来源：arXiv 取论文 ID 前 4 位（如 `2210.03629` → `2210`）；网页取发布日期 `YYYY-MM`（拿不到则用当天）。
- 文件夹 `YYMM-原文标题/`（无 `-bilingual` 后缀）；md 文件名为 `YYMM-原文标题-bilingual.md`（带 `-bilingual` 后缀，避免与已有的同名摘要/笔记冲突）。
- 结构固定为：

```
目标目录/
└── YYMM-原文标题/
    ├── YYMM-原文标题-bilingual.md
    └── images/          # 全部图片（arXiv 保留原名 xxx.svg；网页命名 img-NN.ext）
```

- 若目标目录下已存在同名笔记（如中文摘要），把翻译 md 放同文件夹即可，无需改名——`-bilingual` 后缀已保证 basename 唯一。

## md 头部元信息块

arXiv 论文用：

```markdown
# <中文标题>（中英对照）

> 论文标题：<英文标题>
> 中文标题：<中文标题>
> 论文地址：https://arxiv.org/abs/<ID>
> 项目主页：<有则填，无则省略>
> 代码：<有则填，无则省略>
> 发表：<会议/期刊/年份，如 ICLR 2023（Spotlight）>
> 作者：<作者列表 等（机构）>
> 排版：每段英文原文在前，中文翻译紧随其后。本文收录正文（第 1–N 节与致谢）；附录未收录。
```

在线文章用：

```markdown
# <中文标题>（中英对照）

> 原文标题：<英文标题>
> 原文链接：<URL>
> 原文作者：<作者/网站名>
> 发布日期：YYYY-MM-DD
> 排版：每段英文原文在前，中文翻译紧随其后。默认收录正文主体。

```

> 作者/发表时间：脚本不提取，需要时抓一次 arXiv 摘要页（abs 页）或原文页获取；项目主页/代码一般可从论文或搜索得到，没有就省略。

## 中英对照排版约定（参考 vault 内 2210-ReAct-bilingual 文件）

- **章节标题**：`## 1 引言（Introduction）`（中文在前、英文括号附后）。
- **正文段落**：一段英文原文，空一行，紧接该段中文翻译；术语保留英文并附中文释义。
- **图片**：`![](images/xxx.svg)` 之后跟双语图注：
  ```
  **Figure 1:** <英文图注>
  **图 1：** <中文图注>
  ```
- **表格**：英文表 + 空行 + 中文表（表头翻译，数据不变），表头上方给双语表题。
- **数学公式**：保留 LaTeX（`$...$`，Obsidian 用 MathJax 渲染），不要转成中文。
- **脚注**：原文脚注转为 Obsidian 脚注 `[^n]`，定义行写 `[^n]: <英文> / <中文>`。
- **列表/引用/代码块**：同样英中成对呈现。

## 边界情况（踩过的坑）

- **arXiv HTML 引文编号 bug**：arXiv 生成的 HTML 里文中引用的图/表编号可能与实际不符（如 ReAct v2 把 ALFWorld 结果误引为 "Table 4"、实为表 3；CoT-SC 扩展图误引为 "Figure 1"、实为图 2）。**以提取出的图/表 caption 实际编号为准**修正文中引用，保证文中引用与嵌入图表一致。
- **脚注标号被剥离**：脚本去掉了上标，脚注正文会混进段落末尾。翻译时把这类内容抽出来做成 Obsidian 脚注，不要当成正文。
- **列表重复**：脚本只取 `div.ltx_para`，一般不会重复；若 `extracted.md` 中同一列表出现两遍，翻译时去重只留一份。
- **图片下载失败**：脚本会把失败的图片从 extracted.md 中移除并打印提示。有失败时转告用户（可能需换版本号链接）；arXiv 若需要特定版本，用 `arxiv.org/html/<ID>v<N>` 链接。
- **arXiv 版本**：不带版本号的链接会取**最新版**；用户要旧版时给带版本号的链接。
- **脚本依赖**：`beautifulsoup4`、`readability-lxml`（本机已装）。脚本异常退出时把报错原样转告用户，不要擅自改脚本逻辑。

## 完成标准

- 文件夹含 `-bilingual.md` + `images/`，图片引用全部指向本地相对路径且文件存在。
- 正文逐段英中对照、术语处理一致、图表双语、脚注完整。
- 默认只翻正文；若未翻附录，在文末加一行说明（如"附录 A–D 未收录，如需可补充"）。
- 未擅自 commit。
