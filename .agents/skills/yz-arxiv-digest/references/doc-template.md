# 写作要点

- 表格行从 `curated/<dim>.md` **逐行转录**（ID/日期原样，标题可缩写，要点可在子代理版本上精炼但数字不得改动）；绝不凭记忆补写——实战中曾把别月论文写错进来。
- 同一维度内按日期倒序（curated 文件已是倒序）。
- 趋势条目的信号必须能在正文表格中找到对应论文；Top 12 优先真实数据、可复跑基准、有消融、揭示反直觉结论的工作。
- 附注中的数量全部回填实际值，与校验脚本输出一致。
