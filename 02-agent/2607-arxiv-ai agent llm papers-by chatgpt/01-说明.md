## 主题定义

| 主题 | 定义 | 典型检索词 |
|---|---|---|
| **自进化/自我改进** | 从轨迹、反馈、技能或训练闭环中持续改进 Agent。 | self-evolving, self-improving, co-evolution |
| **评测/Benchmark** | 评估能力、可靠性、成本、失败模式或评测方法本身。 | benchmark, evaluation, grader, failure |
| **记忆/个性化** | 长期记忆的构建、检索、遗忘、版本、个性化与安全。 | memory, episodic, forgetting, personalization |
| **工具/Skill/MCP** | 工具调用、工具发现、Skill 复用、MCP 与执行可靠性。 | tool-use, skill, MCP, function calling |
| **AI Coding Agent** | 代码仓库级任务、SWE-bench、开发流程与代码质量。 | coding agent, SWE-bench, repository |
| **Harness/架构/编排** | Prompt、工具、控制循环、运行时与多步骤编排设计。 | harness, orchestration, workflow, runtime |
| **Agentic RL/训练** | 面向长轨迹决策的 RL、数据飞轮、蒸馏与策略训练。 | agentic RL, policy optimization, trajectory |
| **多智能体** | 多 Agent 协同、决策协议、通信、归因与系统性风险。 | multi-agent, coordination, debate |
| **Web/GUI/Computer Use** | 浏览器、桌面、移动端、深度研究与长流程执行。 | web agent, GUI, browser, deep research |
| **安全/治理** | 注入、越权、记忆投毒、红队、隔离与治理边界。 | prompt injection, attack, authorization, governance |

## 使用提示

- • 分类为多标签：同一论文可同时属于“自进化 + 评测 + 工具”等多个主题，因此分类计数之和会大于论文总数。
- • “相关性分数”只表示与本次检索主题的匹配度，不代表论文质量、引用量或可信度排序。
- • 摘要为英文节选；完整摘要、版本历史、PDF 与代码链接请从 arXiv URL 进入。
